# Content schema

## Units of measure

| Quantity | Unit | Example |
| --- | --- | --- |
| Time | ticks (1 tick = 50 ms) | build time 600 = 30 s |
| Distance, position | 1/256 tile | range 4 tiles = 1024 |
| Speed | 1/256 tile per tick | 4 tiles/s = 51 |
| Multipliers | thousandths | ×1.5 = 1500 |
| Screen sizes (assets) | display pixels at zoom 1.0 | medium unit = 62 |

The content checker rejects any field whose unit is ambiguous. Seconds never appear in content files.

## Asset manifest (`public/assets/manifest.json`)

Generated by `tools/assets/process.py`. Top level:

| Field | Meaning |
| --- | --- |
| `version` | schema version (1) |
| `tilePx` | display pixels per tile at zoom 1.0 (32) |
| `texScale` | textures are stored at this multiple of display size (2) |
| `atlases` | group → list of pages `{image, json, w, h, sprites}`; the JSON is a standard PixiJS spritesheet |
| `assets` | id → record (below) |
| `missing` | assets the pipeline expected and did not find |

Asset record fields by `kind`:

| Kind | Fields |
| --- | --- |
| `unit`, `hero` | `faction`, `w`, `h`, `anchor` [x, y] (feet), `radius` (display px), `facing` ("left"), `flipForRight`, `atlas` [pages] |
| `building`, `hostcell`, `resource` | `faction`, `w`, `h`, `anchor` (footprint centre), `footprint` [tiles w, h], `state` (normal / damaged / alternate), `variantOf`, `atlas` |
| `fx` | `frames` [frame names], `fps`, `blend` ("add" = additive glow, "key" = normal blending), `w`, `h`, `anchor`, `atlas` |
| `icon` | `w`, `h`, `anchor`, `atlas` |
| `map` | `file` (full size), `preview`, `w`, `h`, `tiles` [w, h] |
| `tile` | `file` (512x512, seamless) |
| `portrait`, `ui`, `cinematic`, `reference` | `file`, `w`, `h` |
| `expressions` | `files` [4], `order` ["calm", "happy", "angry", "shocked"] |

Asset ids follow `<kind>_<faction>_<name>`, with factions `wl` (White Line), `col` (Colony), `crn` (Crown) and `neu` (neutral). A damaged building is `<id>_dmg`; the alternate White Line set is `<id>_alt`.

## Game content (`content/`)

| File | Holds |
| --- | --- |
| `content/units/slice.json` | unit definitions (`UnitDef` in `src/sim/content/types.ts`) |
| `content/buildings/slice.json` | building definitions (`BuildingDef`) |
| `content/weapons/slice.json` | weapon definitions (`WeaponDef`) |
| `content/factions.json` | starting conditions per faction |

The slice files are generated from `tools/content/slice_values.py`, which keeps the numbers in human units (seconds, tiles, tiles per second) next to the conversion. Edit the table there and rerun it; do not hand-edit the JSON.

`src/sim/content/catalog.ts` validates everything before a match: integer types and ranges, unique ids, known weapons, tags and buildings, producers that list what they produce, an acyclic requirement graph, starting units that fit the HQ's supply, and (in tests) an asset for every unit and building.

## Maps (`content/maps/*.json`)

| Field | Meaning |
| --- | --- |
| `id`, `name` | map id; Hebrew display name |
| `w`, `h` | size in tiles (8–256) |
| `ground` | tile asset drawn under everything |
| `legend` | character → `open`, `wall` or `blood` |
| `rows` | `h` strings of `w` characters |
| `flows` | currents: `rect` [x, y, w, h] in tiles, `dir` [dx, dy] (normalized when loaded), `strength` 0–1000 ‰ |
| `starts` | HQ top-left tile per start position; each needs 6x6 open tiles |

`tools/content/make_arena.py` generates the gate 2 test arena. `validateMap` (in `src/sim/navigation/grid.ts`) runs before every match.
